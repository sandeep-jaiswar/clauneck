# Probability Theory (mathematics.probability)

## Domain Purpose
Model random events, conditional probabilities, probability distributions, and stochastic processes using Bayes' theorem, expectation, variance, standard probability distributions (normal, binomial, Poisson, exponential), and Markov chains. Supports both theoretical probability calculations and numerical distribution evaluations.

## Input Quantities
- `prior`: prior probability P(A) in [0,1]
- `likelihood`: likelihood P(B|A) in [0,1]
- `evidence`: evidence/marginal probability P(B) in (0,1]
- `joint`: joint probability P(A,B) in [0,1]
- `marginal`: marginal probability P(B) in (0,1]
- `p_a`, `p_b`: individual event probabilities in [0,1]
- `values`: list of random variable values (e.g., [1, 2, 3, 4, 5])
- `probabilities`: list of corresponding probabilities (must sum to 1)
- `x`: evaluation point for distributions
- `mu`: mean of distribution
- `sigma`: standard deviation (must be > 0)
- `k`: number of successes (non-negative integer ≤ n)
- `n`: number of trials (positive integer)
- `p`: success probability in [0,1]
- `lam` or `lambda`: rate parameter (must be > 0)
- `state_probs`: initial state probability vector (must sum to 1)
- `transition_matrix`: transition probability matrix P[i][j], row-stochastic

## Supported Operations (15)

1. **bayes_theorem(prior, likelihood, evidence)** → posterior probability
   - Computes P(A|B) = P(B|A) * P(A) / P(B)
   - All inputs must be valid probabilities
   - Use for disease diagnosis, spam detection, Bayesian inference

2. **conditional_probability(joint, marginal)** → conditional probability
   - Computes P(A|B) = P(A,B) / P(B)
   - Joint probability must not exceed marginal
   - Use for conditional events

3. **joint_probability(p_a, p_b)** → joint probability
   - For independent events: P(A,B) = P(A) * P(B)
   - Both inputs must be valid probabilities
   - Use for simultaneous independent events

4. **expectation(values, probabilities)** → E[X]
   - Computes E[X] = Σ(x_i * P(X=x_i))
   - Probabilities must sum to 1
   - Use for mean value of discrete random variable

5. **variance(values, probabilities)** → Var[X]
   - Computes Var[X] = E[X²] - (E[X])²
   - Probabilities must sum to 1
   - Use for spread/dispersion of random variable

6. **covariance(x_values, y_values, joint_probs)** → Cov(X,Y)
   - Computes Cov(X,Y) = E[XY] - E[X]*E[Y]
   - Joint probabilities must sum to 1
   - Use for dependence between two variables

7. **normal_pdf(x, mu, sigma)** → probability density
   - Evaluates normal (Gaussian) PDF at x
   - sigma (std dev) must be positive
   - Use for continuous normal distribution problems

8. **normal_cdf(x, mu, sigma)** → cumulative probability
   - Evaluates normal distribution CDF: P(X ≤ x)
   - Returns value in (0,1)
   - Use for percentile calculations

9. **binomial_pdf(k, n, p)** → probability mass
   - Evaluates binomial PMF: P(X=k) for n trials, success prob p
   - k must be integer ≤ n, p must be in [0,1]
   - Use for discrete success/failure counts

10. **binomial_cdf(k, n, p)** → cumulative probability
    - Evaluates binomial CDF: P(X ≤ k)
    - Returns value in (0,1)
    - Use for "at most k successes" queries

11. **poisson_pdf(k, lam)** → probability mass
    - Evaluates Poisson PMF: P(X=k) for rate λ
    - k non-negative integer, lambda > 0
    - Use for rare event counts (e.g., arrivals, failures)

12. **poisson_cdf(k, lam)** → cumulative probability
    - Evaluates Poisson CDF: P(X ≤ k)
    - Returns value in (0,1)
    - Use for "at most k events" queries

13. **exponential_pdf(x, lam)** → probability density
    - Evaluates exponential PDF: f(x) = λ * e^(-λx) for x ≥ 0
    - lambda (rate) must be positive
    - Use for continuous waiting times, lifetimes

14. **exponential_cdf(x, lam)** → cumulative probability
    - Evaluates exponential CDF: F(x) = 1 - e^(-λx)
    - Returns value in (0,1)
    - Use for "time until event" probabilities

15. **markov_transition_matrix(state_probs, transition_matrix)** → next state
    - Computes π_{n+1} = π_n * P for Markov chain
    - State probs must sum to 1; transition matrix must be row-stochastic
    - Returns list of probabilities for each state after one step
    - Use for stochastic process evolution

## Solver Method Recommendation
- Use `SYMBOLIC_SOLVE` for closed-form probability calculations (Bayes, distributions)
- For large state spaces or long-run behavior (Markov chains), may need numeric iteration
- All operations are deterministic; results are reproducible
